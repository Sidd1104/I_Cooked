## 🌟 Overview

The **Netflix Developer Portfolio** transforms traditional flat resumes into an interactive, streaming-inspired narrative. Structured as a high-production developer series (**"Siddhant's Dev Series"**), it guides recruiters, engineering managers, and collaborators through technical milestones, production-shipped projects ("Blockbusters"), professional internships, academic distinction, and engineering capabilities with cinematic fidelity.

* **Live Deployment:** [https://siddhantportfolio-two.vercel.app/](https://siddhantportfolio-two.vercel.app/)
* **Engineered By:** Siddhant Mohan Jha (Full-Stack Developer · BCA 3rd Year, 5th Sem, GL Bajaj Institute of Management)

## ✨ Key Features

- **🔴 Signature Netflix Preloader**: Cinematic ribbon intro animation and branded splash screen orchestrating autoAlpha fade transitions.
- **✨ Physics-Driven Custom Cursor & Spotlight**: Dual-element precision cursor with real-time `quickTo` physics and an ambient mouse-following radial spotlight beam.
- **🎴 3D Hologram Tilt Card**: Hero stage featuring interactive mouse-tracked 3D card tilt, dynamic specular glare mapping, and layered neon back-glow.
- **🍱 Bento Grid Architecture**: Episode 01 modular layout detailing academic foundations, competitive milestones, and core production technologies.
- **🃏 Sticky Gradient Stacking**: Episode 02 stacked card mechanism driven by GSAP ScrollTrigger, creating dynamic perspective scale and blur transitions as the user scrolls.
- **🎡 3D Cylindrical Skills Arsenal**: Episode 03 interactive 3D rotation carousel mapping six distinct technology domains on desktop with a native swipe snap view on mobile.
- **📁 3D Archive Folder Project Showcase**: Episode 04 animated folder flap opening sequence deploying a clean 2×3 grid on desktop and a smooth swipe carousel on mobile.
- **⚡ Laser-Scrubbed Internship Timeline**: Episode 05 progressive timeline drawing animated laser progress lines and pulse nodes across four verified software engineering internships.
- **🎓 Horizontal Academic Roadmap**: Episode 06 milestone track tracing schooling to university tenure, accompanied by an animated count-up CGPA match badge (0.00 → 8.54 / 10).
- **🏆 3D Unlockable Hall of Fame**: Episode 07 achievement cards featuring scroll-triggered 3D flip-reveal animations, glowing pulse borders, and loot-box sweep shines.
- **📬 Production Formspree Contact Portal**: Episode 08 functional contact system with client-side field validation, permission checkboxes, sending spinner, and success/error transmission feedback states.
- **📱 Fully Responsive**: Engineered from mobile ultra-compact displays up to 4K desktop screens.

## 🚀 Getting Started

To run the project locally on your machine:

### Prerequisites

* **Node.js**: `v18.0.0` or higher
* **npm**: `v9.0.0` or higher (or `pnpm` / `yarn`)

### 1. Clone the Repository

```bash
git clone https://github.com/Sidd1104/I_Cooked.git
cd I_Cooked
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Local Development Server

```bash
npm run dev
```

The portfolio will be available at `http://localhost:3000/` (or with `--host` at `http://<your-network-ip>:3000/`).

### 4. Build for Production

```bash
npm run build
```

The optimized production bundle will be generated in `dist/`, ready for zero-configuration deployment on [Vercel](https://vercel.com/), [Netlify](https://netlify.com/), or [GitHub Pages](https://pages.github.com/).
